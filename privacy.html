MyNode1 Backups

Privacy policy

Effective November 19, 2026.

Purpose and data access

MyNode1 Backups is intended solely for the server owner's personal disaster recovery. It uses Google Drive API access limited to files created or opened by the application (drive.file). It uploads encrypted backup archives, lists backup locations and verifies file sizes and checksums. It does not request access to Gmail, Google Photos or the owner's entire Drive.

Use and storage

Backup data is used exclusively for backup and recovery. Archives are encrypted with AGE before transfer to the owner's Google Drive. OAuth credentials are stored in access-restricted local configuration; the backup decryption key is kept separately. Backup file names, sizes and checksums may be visible in Drive and local operational logs. The application does not sell Google user data, use it for advertising, or transfer it to unrelated third parties. Google Drive is the cloud storage provider; GitHub Pages hosts this informational website.

Retention and deletion

The owner controls backup retention and may delete archives from Google Drive or instruct the backup utility to remove them. The owner may revoke the application's Google account access at any time from Google Account connections. Revoking access stops future authorized API operations but does not itself delete previously uploaded files.

Google API data policy

Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

For questions or deletion requests, contact the maintainer via the project issue tracker. Do not post backup contents, credentials or private information in public issues.
