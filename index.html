PERSONAL INFRASTRUCTURE UTILITY

MyNode1 Backups

MyNode1 Backups is a private, single-owner utility for sending encrypted server backup archives to the owner's Google Drive using Rclone.

Backup archives are encrypted before upload. The utility requests per-file Google Drive access (drive.file) to create and verify its backup files. It is not a public backup service and does not offer registration.
